# Un evento de finalización por turno

Una sesión delegada puede recibir varios encargos a lo largo de su vida. Session Scheduler emite un MCP Event por cada turno que termina, incluidos los que fallan o se cancelan, con los identificadores de sesión y turno y el motivo de cierre. Así Dot conoce el desenlace de cada encargo mientras la sesión queda disponible para dar seguimiento.
